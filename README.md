# 企业级全响应式排版系统

**零依赖 · 单文件 · 双击即用** 的可视化 HTML 布局设计器。基于绝对定位 + vh 等比缩放体系，专为可视化大屏、仪表盘、固定布局页面设计。

---

## 快速开始

1. 双击打开 `index.html`
2. 右键画布空白处 → **添加元素**，或使用模板插入
3. **拖拽**移动元素，**八向缩放手柄**调整尺寸
4. 右键元素 → 编辑 HTML / JSON / 样式
5. 导出为静态 HTML 或 JSON 存档

零配置，零安装，纯浏览器端运行。

## 核心功能

### 画布操作

| 操作 | 说明 |
|------|------|
| 拖拽移动 | 选中元素后拖动，自动吸附对齐线 |
| 八向缩放 | 拖拽元素八个方向的缩放手柄 |
| 智能对齐 | 边缘对齐（红）、中心对齐（蓝）、画布中心（紫）、等距对齐（绿）、尺寸对齐（橙） |
| 箭头键微调 | `↑↓←→` 精确移动，按住 `Shift` 加速 |
| 预览模式 | 右键画布 → 编辑预览查看，或 `ESC` 退出 |

### 元素右键菜单

- **编辑元素 HTML** — Monaco Editor 内嵌编辑，支持 CSS / JS
- **编辑元素 JSON** — 直接修改元素的 JSON 配置项
- **自适应高度** — 开启后元素高度由内容撑开，下方元素级联联动平移
- **对齐方式** — 居左、水平居中、居右、顶端、垂直居中、底端对齐
- **图层顺序** — 置于顶层 / 上移 / 下移 / 置于底层
- **图层管理** — 可视化图层面板，支持重命名、锁定、隐藏、拖拽排序
- **复制 / 删除** 元素
- **复制元素 ID 编码**

### 画布右键菜单

- 添加元素 / 模板插入
- 图层管理
- **页面背景设置** — 纯色 / 图片背景，支持调节不透明度与显示模式
- **全局 CSS / JS 设置** — 对整个画布注入自定义样式或脚本
- 导出静态 HTML / 导出布局 JSON / 导入布局 JSON
- 清空画布（二次确认）

### 模板系统

内置多套预置模板（卡片、面板、图表容器等），右键画布 → **模板插入** 即可使用。

### AI 辅助生成

集成 DeepSeek API，在编辑器中输入自然语言提示词，AI 自动生成/修改 HTML 代码。需要自行填入 DeepSeek API Key（Key 仅保存在浏览器本地）。

## 设计体系

### 坐标系统

- **绝对定位**（`position: absolute`）：像素级精确控位
- **vh 等比缩放**：位置和高度以视口高度百分比存储，窗口缩放时比例自洽
- **横向宽度**：百分比存储，适配不同宽度

### 自适应高度

一种特殊的布局模式，开启后：

1. 元素高度由内容实际渲染高度决定（`height: auto`）
2. `ResizeObserver` 监听内容尺寸变化
3. 下方所有元素**级联平移**，保持相对间距不变
4. 窗口缩放时用快照修正算法确保位置一致性

适用场景：内容动态变化的卡片、评论区、折叠面板等。

### 数据持久化

- **自动保存**：每次操作后自动写入浏览器 `localStorage`
- **JSON 导出/导入**：完整序列化布局状态，可跨设备迁移
- **静态 HTML 导出**：生成独立运行的 HTML 文件，不依赖编辑器
- **撤销/重做**：最多保留 50 步历史

## 适用场景

- 数据可视化大屏
- 控制台 / 后台管理界面
- 固定布局的 Web 页面
- HTML 邮件模板
- 快速原型设计

---

## 不适用场景

- 需要响应式布局的页面（vh 体系不做断点适配）
- 长文档流排版（绝对定位不处理文档流）
- 复杂组件嵌套（元素之间无父子语义关系）

---

## 技术细节

- 纯前端，无后端依赖
- Font Awesome 6.5 CDN 图标库（需联网）
- Monaco Editor CDN（编辑 HTML/JSON 时代码高亮）
- 内置 XSS 防护（HTML 属性/样式/脚本安全转义）
- `localStorage` 容错处理（隐私模式 / QuotaExceeded 降级）
